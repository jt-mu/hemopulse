Retained recipient request relationships

Tables without foreign-key relationships: login_attempts, newsletter_subscriptions, request_limits. Their complete columns are in the dictionary below.
Program boundaries: APIs are operations, not entities. Blood inventory links to donations through inventory_transactions. Public emails do not link to users by FK. OTPs and CSRF tokens live in PHP sessions. Profiles and mail previews are files. SMTP is an external transport. The recipient fulfillment handler is disabled (410); no active request/threshold mutation API exists. Current throttling uses request_limits, not login_attempts.

Main JSON APIs

Base: /hemopulse/api/index.php/. Collection POST; item PUT/DELETE where shown. Session cookies authenticate; mutations require X-CSRF-Token. Public reads: session, campaigns, categories. GET inventory and staff reports may write expiry updates. See the notes in the Markdown guide for behavior and access details.
